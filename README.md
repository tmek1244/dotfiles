# Dotfiles

## Installing

Clone into your $HOME directory
```bash
git clone git@github.com:tmek1244/dotfiles.git ~
```

`cd` into repo and run `stow` to symlik configs e.g.
```bash
stow zsh
```


## macOS

Run `install-macos.sh`, then follow [MACOS.md](MACOS.md) for the system
shortcuts that have to be changed by hand and the full Karabiner shortcut map.
